# 每日轻量力量训练 V1.4.0

纯静态 GitHub Pages/PWA，基于 V1.3.0 完整包。无需构建或后端；目标 Safari iOS/iPadOS 15 及以上。实际苹果设备兼容性待验收。

## 给使用者

1. 打开首页，点击「开始跟练」即可。每天自动推荐固定两周循环计划（周一/三/五 A/B 交替，其余恢复日），不随机，不自动加重。
2. 跟练时可暂停、继续、跳过或停止。热身/休息计时到零后等待本人点击继续，休息可增加15秒。不适即停。结束自动保存本次记录，返回首页即可看到日历。
3. 需要时才点击「调整训练」修改单项次数，或全部加减一次；「更换计划」手动选择当天训练组。训练次数下次仍保留。单侧动作按每侧次数计算。
4. 周日历可查看今天及过去的日期，选择日期后可补录、编辑和删除记录。不设置漏练惩罚。计划与实际记录分开。
5. 右上「设置 · V1.4」包含语音、可选动作、更新、备份、打印材料；平时不需要打开。

## 训练内容

默认全部坐姿；原 05 仰卧脚跟滑动退出默认训练和动作库（旧素材保留以便维护）。常用动作库共10项，保持原编号：01 弯举、02 肩外旋、03 低位侧抬、04 伸膝、06 提踵、07 抬脚尖、08 腕屈伸；09 划船、10 扶持站姿屈膝、11 扶持站姿提踵为可选。可选动作默认关闭，仅在专业评估确认允许后由使用者或家人进入设置启用；此选项会同时启用三项候选动作，不是安全认证。坐姿方案仍需遵守专业人员给出的限制。插画仅示意，未经过临床康复人员审核。

默认 A 15:15、B 16:05，启用候选 A 15:15、B 16:15；恢复日20:00。单次5秒（用力2秒/还原3秒），每动作1组，换边10秒，动作间45秒；最后直接放松。热身/放松各3分钟，不强行凑满20分钟。上肢及伸膝默认8次（4–12）；坐姿踝部动作、站姿提踵默认12次（6–15）；站姿屈膝每侧6次（4–10）。次数不是医疗处方，按专业建议调整。

## 更新部署

先结束当前训练、导出一次记录备份。在原仓库根目录覆盖解压新版 ZIP（index.html 与 .git 同级）。检查 git status 后提交并 push；不提交备份或 ZIP。GitHub Pages 仍使用 main / root，不需要 npm、数据库或任何编译工具。

旧版页面如提示新版，先应用更新；V1.4 右上设置中有「检查更新」与「应用新版」。应用新版时需关闭其他本应用标签页。清除程序缓存并重载需联网，仅尝试注销当前 scope 的 Service Worker 并清除其专属缓存，不主动删除 localStorage 或其他项目缓存。切勿把它与 Safari 系统「清除网站数据」混淆。此流程需真机测试；若遇到旧版页面无法更新，先备份，再考虑浏览器系统清理。

## 数据兼容

继续使用 gentle-strength-v1 本地存储键、原记录字段和 schema 1 JSON 导入导出。新增 day（本地训练日）、source、reps、expanded 字段；旧记录按 date 转换本地日期。自动记录使用开始日及会话ID，避免重复保存；提前结束或跳过非休息环节计为部分完成；跳过休息不影响完成判断。旧版本未完成草稿无法按新环节恢复时，会尝试保存为部分记录，不强行映射。新版草稿保存训练参数快照。

记录仅在本机存储，不自动同步，不保证在系统主动清理或空间不足时永不丢失。建议只在同一设备的同一应用窗口训练，避免多窗口同时修改；跨设备通过 JSON 备份手动合并。备份文件主要保存记录，不包含设置。自动记录不要求填写身体反馈；完成页可选记录轻松/适中/吃力，旧反馈字段保留。

## V1.4 语音及跟练交互

- 新安装默认启用中文语音和轻提示音；从旧版本升级保留原有语音开关。原先关闭语音的用户需在「设置 · V1.4」打开「中文语音指导」并试听。
- 使用浏览器 SpeechSynthesis，只选择明确标记 localService=true 的中文语音，优先普通话。无本机语音、浏览器阻止播放或语音异常时，提示查看文字，训练计时不依赖语音回调。无远程语音 API，不上传训练记录。
- 首次点击开始/继续或试听时直接发起语音，适应 iOS 用户交互限制。每个动作朗读名称、侧别、实际次数、动作要领与呼吸提示；热身、休息、放松及结束也有提醒。暂停、离开页面、后台切换会取消朗读；可点「再听要领」。不逐次强制朗读，避免与动作节奏冲突。
- 轻提示音用 Web Audio 生成，与语音分开开关；不使用震动。
- 如听不到：检查语音开关、媒体音量、系统中文语音是否可用（设置→辅助功能→朗读内容→声音，具体名称随系统版本变化），联网下载语音后再试听；再测试断网播放。旧 iPad 实际支持情况以真机为准。
- 热身、组间休息及换边到零时等待用户继续，动作练完自动进入休息。可在休息中提前继续或增加15秒（每环节累计最多增加5分钟）；等待确认的时间不计入计时记录，增加的休息计入计划及实际时间。默认训练模板、次数与候选动作开关不变。
- 首页显示器材，动作页及跟练页可查看起止姿势；跟练中可按需切换，不改变计时。完成页自动保存，感受填写可选。
- 家人设置新增文本备份兜底（手动复制/粘贴），仍使用 schema 1 并按 ID 去重。仅记录备份，不包含所有设置。V1.3 草稿可按原有环节恢复，V1.4 草稿附加休息延长量。
- 真机兼容未验收；无本机中文语音时不自动使用远程语音。没有修改训练动作、负重、适用范围和插画。月度日历、随机计划、震动暂不做。
