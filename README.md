# 每日轻量力量训练 V1.1.0

面向 iPhone 13（iOS 17）和 iPad Pro 9.7 英寸（目标 iPadOS 15/16）的静态跟练参考工具。无需构建、服务器、账户、外部 CDN 或网络 API。

## GitHub Pages 部署（约定：仓库根目录）

1. 解压 ZIP，将 `index.html`、`style.css`、`app.js`、`data.js`、`sw.js`、`manifest.webmanifest`、`.nojekyll`、`assets/`、`printable/` 原样放到仓库根目录。README 可一并上传。`make_assets.py` 仅为生成素材的开发脚本，不需要运行，也不需要上传。
2. 仓库 Settings → Pages → Build and deployment → Source: Deploy from a branch；选 main / (root)，保存。
3. 打开 Pages 给出的 HTTPS 地址，使用 Safari。首次联网等待页面显示“离线缓存已启用”。Safari 分享 → 添加到主屏幕，然后在主屏幕打开，再联网确认缓存状态。
4. 后续从主屏幕同一图标进入。Safari 标签页与主屏幕应用的记录可能分开，建议固定使用一个入口。

没有默认的远程提交或账号。Pages 地址可公开访问；不要把健康记录、姓名、个人备份 JSON 或密钥提交到仓库。应用本身不向服务端发送训练记录。

## 更新

训练内容集中在 `data.js`。更新时同时修改 `TRAINING.version`、`sw.js` 的缓存版本、`index.html` 的显示版本；新增资源时添加到 `ASSETS`，新增动作同步修改动作图和打印版。提交后 GitHub Pages 自动发布。Service Worker 在后台安装完整新版本，不强制刷新训练中页面；训练结束后关闭该站点所有 Safari 标签页及主屏幕应用，重新打开。V1.1 及以后若检测到更新，今日页显示「应用新版（保留记录）」；如果有其他同站点标签页，先关闭其他页面。V1.0 升级到 V1.1 时旧版没有该按钮，按关闭全部页面并重新打开的方法更新。若未更新，联网重新打开并确认版本。保持原 URL（协议、域名及路径）以延续记录和缓存；本地记录 schema 不随缓存更新清除。V1.1 每秒保存同版本训练草稿，刷新或关闭后恢复到暂停状态，须主动继续。新版安装前仍应结束并保存本次训练；跨版本草稿不自动迁移。

## 数据与隐私

使用 localStorage 保存少量历史记录（而不是 IndexedDB），便于维护。记录日期、计划、实际计时、完成状态、计划版本、可选症状反馈。数据只保存在本设备当前网页容器，未做跨设备同步。导出/导入 JSON 使用合并和记录 ID 去重；导出文件可自行放入 iCloud Drive，但包含健康反馈，应私下保管。存储可能被系统回收或主动清除，定期备份。备份功能不代表 iCloud 自动同步。

## 训练边界

本工具是一般性参考，不是个体医疗处方。对于有症状的 II 度脱垂，开始抗阻前应经妇科或盆底康复专业人员评估；不因日常活动不受限即认定任何负重安全。膝痛者只在舒适范围内活动。先 1 组，每动作 8 次；轻水瓶 250–500g 或空手，1kg 仅为经允许且适应后的部分动作备选，不自动加重。仰卧脚跟滑动是活动/激活练习，不等于负重抗阻。每周非连续三天 A/B 交替，其余日为舒缓活动或休息。每日 20 分钟包含较长休息，允许缩短或跳过。插画和 GIF 是动作方向示意，未经临床人员审定。动作库 GIF 每周期 5 秒；跟练页使用同源精灵图逐帧显示，用力约 2 秒、还原约 3 秒，计时暂停时画面也冻结。

训练中或后坠胀、突出感、漏尿或膝痛加重则停练；持续或明显加重需就医。出血、剧烈疼痛或无法排尿应及时就医。不要憋气、不向下用力；不安排腰腹主动强化、重负荷深蹲、跳跃。未提供脱垂治疗处方。

## 真机验收（尚未完成）

- iPhone 13 竖屏、iPad 9.7 横/竖屏：无横向滚动、按钮可点击、文字不裁剪；Safari 和主屏幕模式分别检查。
- 首次联网缓存完毕，再开启飞行模式，关闭并重开主屏幕 App：A/B/恢复日、8 GIF、打印图均可访问。
- 开始后跳过、暂停、继续、退出，锁屏或切后台后回到前台应保持暂停；无需依赖后台计时。iOS 不保证屏幕常亮，长训练可临时延长自动锁屏设置。
- 中文语音由系统提供，未必有离线中文语音；无语音时仍有文字提示。开始及切换环节可播报；不保证每次呼吸播报。
- 保存和重启后记录仍可见；导出到“文件”，再导入应合并去重。确认两台设备记录默认独立。
- 发布修改版本后，结束训练、关闭所有该站点页面再打开，版本和素材一致且旧记录保留。

## V1.1 修订摘要

- 8 个动作统一为中性人体康复插画；每个动作独立 GIF、起始和终点 PNG、25 帧精灵图，统一 5 秒周期。更新 A4 PDF 和一页纸 PNG。
- 单调时钟（performance.now）测量真实前台经过时间；短延迟不直接丢失，超过 2 秒的卡顿自动暂停，不跨多个动作追赶。暂停冻结画面，跳过与实际用时分开统计，左右侧分别计时并提供 10 秒换边。小屏固定结束按钮。
- 同版本未完成会话草稿恢复为暂停；已保存记录按会话 ID 去重；继续保留原 localStorage 记录键，升级不主动清除记录。
- 缓存名绑定站点 scope，避免同一 GitHub Pages 域名的其他项目缓存被清除；有完整新包才安装；仅空闲且无其他同站点窗口时允许主动更新。
