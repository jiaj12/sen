# 每日轻量力量训练 V1.3.0

纯静态 GitHub Pages/PWA，基于 V1.2.0 完整包。无需构建或后端；目标 Safari iOS/iPadOS 15 及以上。实际苹果设备兼容性待验收。

## 给使用者

1. 打开首页，点击「开始跟练」即可。每天自动推荐固定两周循环计划（周一/三/五 A/B 交替，其余恢复日），不随机，不自动加重。
2. 跟练时可暂停、继续、跳过或停止。不适即停。结束自动保存本次记录，返回首页即可看到日历。
3. 需要时才点击「调整训练」修改单项次数，或全部加减一次；「更换计划」手动选择当天训练组。训练次数下次仍保留。单侧动作按每侧次数计算。
4. 周日历可查看今天及过去的日期，选择日期后可补录、编辑和删除记录。不设置漏练惩罚。计划与实际记录分开。
5. 右上「设置 · V1.3」包含语音、可选动作、更新、备份、打印材料；平时不需要打开。

## 训练内容

默认全部坐姿；原 05 仰卧脚跟滑动退出默认训练和动作库（旧素材保留以便维护）。常用动作库共10项，保持原编号：01 弯举、02 肩外旋、03 低位侧抬、04 伸膝、06 提踵、07 抬脚尖、08 腕屈伸；09 划船、10 扶持站姿屈膝、11 扶持站姿提踵为可选。可选动作默认关闭，仅在专业评估确认允许后由使用者或家人进入设置启用；此选项会同时启用三项候选动作，不是安全认证。坐姿方案仍需遵守专业人员给出的限制。插画仅示意，未经过临床康复人员审核。

默认 A 15:15、B 16:05，启用候选 A 15:15、B 16:15；恢复日20:00。单次5秒（用力2秒/还原3秒），每动作1组，换边10秒，动作间45秒；最后直接放松。热身/放松各3分钟，不强行凑满20分钟。上肢及伸膝默认8次（4–12）；坐姿踝部动作、站姿提踵默认12次（6–15）；站姿屈膝每侧6次（4–10）。次数不是医疗处方，按专业建议调整。

## 更新部署

先结束当前训练、导出一次记录备份。在原仓库根目录覆盖解压新版 ZIP（index.html 与 .git 同级）。检查 git status 后提交并 push；不提交备份或 ZIP。GitHub Pages 仍使用 main / root，不需要 npm、数据库或任何编译工具。

旧版页面如提示新版，先应用更新；V1.3 右上设置中有「检查更新」与「应用新版」。应用新版时需关闭其他本应用标签页。清除程序缓存并重载需联网，仅尝试注销当前 scope 的 Service Worker 并清除其专属缓存，不主动删除 localStorage 或其他项目缓存。切勿把它与 Safari 系统「清除网站数据」混淆。此流程需真机测试；若遇到旧版页面无法更新，先备份，再考虑浏览器系统清理。

## 数据兼容

继续使用 gentle-strength-v1 本地存储键、原记录字段和 schema 1 JSON 导入导出。新增 day（本地训练日）、source、reps、expanded 字段；旧记录按 date 转换本地日期。自动记录使用开始日及会话ID，避免重复保存；提前结束或跳过非休息环节计为部分完成；跳过休息不影响完成判断。旧版本未完成草稿无法按新环节恢复时，会尝试保存为部分记录，不强行映射。新版草稿保存训练参数快照。

记录仅在本机存储，不自动同步，不保证在系统主动清理或空间不足时永不丢失。建议只在同一设备的同一应用窗口训练，避免多窗口同时修改；跨设备通过 JSON 备份手动合并。备份文件主要保存记录，不包含设置。自动记录不再要求填写身体反馈，旧反馈字段仍保留以兼容历史。
